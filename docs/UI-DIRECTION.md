# Historical UI direction — OlyHub OH-004.3.0

> **Superseded by the current Poseidon/Zeus product architecture.** The old Zeus/Olympus mode selector described below is historical and must not be reintroduced. The current primary chat is Poseidon Text; Live Talk is Poseidon Voice; Zeus is a separate director/auditor shell.

OlyHub should feel like a premium AI operating environment, not a dashboard template. The production visual language is a near-black canvas, graphite depth, restrained metallic-gold accents, white/silver content and very quiet status color.

## Hierarchy
- **Desktop:** persistent left navigation, quiet centered OlyHub brand, small current-workspace context, content-first main canvas.
- **Mobile:** compact header with the ☰ menu button opening a drawer for Home / Projects / Tools / Files / Settings and Home chat history (the former bottom navigation was removed in the nav simplification).
- **Home (historical):** goal-first chat experience with the former Zeus/Olympus mode selector. Current Home presents Poseidon as the coordinator and does not expose a mode or level selector.
- **Projects:** each Project is a self-contained workspace. Project cards communicate status, progress and continuity. Inside a Project, Chat / Overview / Tasks / Files / Memory read as one product.
- **Tools:** capabilities are explicit and honest. Unsupported capabilities remain visually subordinate and disabled.
- **Files:** outputs prioritize filename, type, recency and a single clear open/download action.

## Visual rules
- Gold is an accent, never a full-page fill.
- Avoid bright blue SaaS-dashboard styling.
- Use subtle borders and depth rather than heavy shadows everywhere.
- Headings are compact and editorial; utility copy is small and quiet.
- Avoid oversized mobile buttons unless they are the primary action.
- Preserve strong focus-visible states and reduced-motion behavior.
