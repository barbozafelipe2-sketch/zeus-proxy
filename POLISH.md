# OH-004.3.4 — Polish

This pass changes product presentation, source-grounding discipline, long-attachment selection, and release verification. It does not add a database migration.

## Product position
- Zeus is the default day-to-day mode.
- Olympus is a bounded specialist synthesis mode for genuinely multi-domain work.
- Web Search remains disabled/not configured until a real retrieval adapter exists.
- Supplied files/project context are primary evidence. Unsupported claims must be called out rather than invented.
- OlyHub never claims current-web research or executed tests unless the runtime actually performed them.

## Long documents
Current-turn attachments use query-aware excerpts when extracted text exceeds the per-file prompt budget. OlyHub keeps the beginning/end plus the most query-relevant windows rather than always taking only the first characters. This improves source review without pretending the entire document is in the active prompt.

## Release gate
`npm test` remains the local verifier/unit-contract suite. `npm run smoke:live` is the live deployed-environment smoke harness and requires explicit credentials/environment variables. These are separate gates and must not be described as equivalent.

## Lockfile
Direct dependencies and Node/npm toolchains are pinned, and a real npm v3 `package-lock.json` is included. The lockfile was generated by GitHub Actions from the exact 4.3.4 manifest; CI verifies installs with `npm ci`.
