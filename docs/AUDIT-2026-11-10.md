# Repository audit — 2026-11-10

Baseline: `71180d1` on main. This report covers code and automated validation, not certification of the deployed sites, their credentials, databases or browser voice sessions.

## Findings corrected

1. **High dependency advisory:** pptxgenjs pulled image-size 1.2.1, affected by parser denial-of-service advisories GHSA-5p2g-fcmc-qvqq and GHSA-w3rx-r6r6-pgpr. Pin its transitive image-size to 2.0.4; preserve pptxgenjs 3.12.0. Regenerated the lockfile and generated a real PPTX with an embedded PNG successfully.
2. **Sequential context reads:** seven independent project-scoped reads were serialized. Run them in Promise.all while retaining owner/project filters, limits, memory selection and context redaction. A deferred-query test verifies concurrency and scope.
3. **Unloaded Realm inventory:** loadRealmInventory existed but was never called from Realm navigation. Load it when entering Realms and use its workflow associations instead of a separate frontend workflow map.
4. **Misleading model counts:** the UI counted models but called them provider families. Label them as models with configured routes.
5. **Stale routing inventory:** Realm inventory claimed direct recovery was disabled. Report the actual explicitly configured Google/OpenAI recovery providers, without credentials.
6. **Direct-only false unavailability:** health and specialist candidate selection ignored direct recovery even though the chat executor supported it. Include task-appropriate direct candidates in text/vision readiness and specialist selection. Gateway ordering remains enforced by the executor.
7. **Missing transport evidence:** successful direct recovery was always reported as unused. Derive recovery from recorded attempts and summarize direct transport evidence independently from Gateway circuits.
8. **Gateway health fallback:** an object containing only false provider flags was considered configured because the object itself was truthy. Evaluate its boolean values.
9. **Stale test contracts:** Realm and navigation tests still expected the removed Equipe screen and an exact English hamburger label. Update them to validate the current canonical Realms UI, runtime inventory and Portuguese accessible navigation.
